# Joseph Gakumo Munyui

A single-page portfolio compiled from the public GitHub accounts [JoeGakumo212](https://github.com/JoeGakumo212) and [JoeGakumo21](https://github.com/JoeGakumo21).

Routes: `/`, `/work`, `/work/:slug`, `/about`, `/contact`.

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
npm run preview
```
